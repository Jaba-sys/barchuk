# Барчук Бекери — веб-версия

## Структура файлов (не переименовывай их, иначе ссылки внутри файлов сломаются)

```
barchuk-bekery-web/
├── index.html       ← главный файл, открывается в браузере
├── style.css        ← вся визуальная часть (подключается из index.html)
├── script.js        ← вся логика игры (подключается из index.html)
└── assets/
    └── barchuk.png   ← картинка Барчука
```

Все три файла (`index.html`, `style.css`, `script.js`) и папка `assets/` должны
лежать **в одной директории**, с точно такими же именами — они ссылаются друг
на друга по относительному пути (`href="style.css"`, `src="script.js"`,
`assets/barchuk.png`).

## Как выложить на GitHub Pages

1. Создай новый репозиторий на GitHub, например `barchuk-bekery`.
2. Залей в него ровно эти файлы, сохранив структуру (`index.html` — в корне
   репозитория, `assets/barchuk.png` — в подпапке `assets`).
3. Зайди в `Settings → Pages`, в поле `Source` выбери ветку `main` и папку
   `/ (root)`, сохрани.
4. Через минуту-две игра будет доступна по адресу вида
   `https://<твой-логин>.github.io/barchuk-bekery/`.

## Локальный запуск

Можно просто открыть `index.html` двойным кликом — браузер загрузит
`style.css`, `script.js` и картинку сам. Если браузер ругается на
`CORS`/`file://` (редко бывает с картинками), запусти локальный сервер из
папки проекта:

```bash
python3 -m http.server 8000
```

и открой `http://localhost:8000`.

## Управление

- **Пробел** — открыть/закрыть дверь
- **C** — открыть/закрыть камеры (или клавиша **Esc**, чтобы выйти)
- **1 / 2** — переключение между камерой коридора и камерой зала, когда монитор открыт

## Что исправлено по сравнению с первой версией

- Кнопки «Дверь» и «Камеры» теперь всегда поверх монитора — можно закрывать
  дверь, даже глядя в камеры, и выходить из монитора кнопкой «✕ Выйти».
- Камера коридора теперь настоящий уходящий вдаль коридор (перспектива,
  мерцающие лампы, дверной проём в конце), и Барчук на ней визуально
  приближается по мере того, как бежит к твоей двери.
