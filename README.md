# Барчук Бекери — веб-версия (3 страницы)

## Структура файлов (не переименовывай — файлы ссылаются друг на друга по этим именам)

```
barchuk-bekery-web/
├── index.html         ← главное меню (открывать первым)
├── game.html           ← сама игра
├── ending.html          ← концовка (доступна только после победы в game.html)
├── css/
│   ├── base.css          ← общие цвета/шрифты/кнопки для всех страниц
│   ├── menu.css           ← стили только для index.html
│   ├── game.css            ← стили только для game.html
│   └── ending.css           ← стили только для ending.html
├── js/
│   ├── audio.js             ← общий синтезированный звук (без файлов .mp3/.wav)
│   ├── achievements.js       ← список достижений + сохранение в localStorage
│   ├── menu.js                 ← логика index.html
│   ├── game.js                  ← вся логика игры
│   └── ending.js                 ← логика концовки (см. ниже про защиту)
└── assets/
    └── barchuk.png              ← картинка Барчука
```

## Как выложить на GitHub Pages

1. Залей все файлы и папки в репозиторий, сохранив структуру как есть
   (`index.html` — в корне репозитория).
2. `Settings → Pages → Source: main / (root)`.
3. Через минуту-две игра будет на `https://<логин>.github.io/<репозиторий>/`.

## Локальный запуск

Открой `index.html` двойным кликом, либо через локальный сервер из папки:
```bash
python3 -m http.server 8000
```
и зайди на `http://localhost:8000`.

## Баланс энергии

- Открытые дверь и вентиляция без действий — энергия медленно восстанавливается.
- Открытые камеры — тратят энергию, но медленно (~1.2%/сек).
- Закрытая дверь **или** закрытая вентиляция — тратят энергию гораздо быстрее
  (~7%/сек каждая — можно и обе сразу, тогда расход суммируется).
- Если энергия упадёт до нуля — она **больше не восстановится до конца ночи**.
  Дверь и вентиляция при этом окончательно распахиваются и становятся
  недоступны — следующая атака Барчука через любой из двух путей гарантированно
  убьёт.
- Пока открыт монитор камер, ни дверь, ни вентиляцию закрыть **нельзя** —
  нужно сначала выйти из камер.
- У двери и у вентиляции — фиксированные 3 секунды на закрытие, затем ещё
  4 секунды Барчук "стоит" у закрытой преграды, прежде чем отступить (всё это
  время она должна оставаться закрытой).
- Скорость перебежки по коридору каждый раз случайна: "быстро" или "очень быстро".
- С шансом ~35% вместо коридора Барчук лезет в вентиляцию — тогда он пропадает
  с ОБЕИХ камер (коридор и зал) на 6-18 секунд, пока не появится прямо в решётке
  вентиляции в кабинете. Никакого предупреждения по камерам не будет.

## Достижения

Хранятся в `localStorage` браузера (переживают перезагрузку страницы, привязаны
к конкретному браузеру/устройству). Список показывается в главном меню.
Достижения начисляются при успешном прохождении ночи в `game.html`, конкретный
набор зависит от того, как прошла смена (сколько раз закрывал дверь, случался
ли обрыв энергии, минимальный уровень энергии, сколько было быстрых забегов).

## Защита страницы концовки

`ending.html` специально не открывается напрямую по ссылке или через
"допиши в адресной строке .html" — при выигрыше `game.html` кладёт в
`sessionStorage` короткоживущий (20 секунд) токен, и `ending.html` проверяет
его наличие при загрузке; если токена нет или он просрочен — мгновенный
редирект обратно в `index.html`, без показа сюжета концовки.

Важно понимать: это ограничение полностью на стороне браузера (JavaScript),
а не серверная защита — оно не пускает случайное редактирование URL, но не
является "настоящей" защитой от того, кто откроет консоль разработчика и
пропишет токен руками. Для простой браузерной игры без сервера это
стандартный практический предел.

## Управление

- **Мышь** — клик по любой кнопке (Дверь, Вентиляция, Камеры, вкладки камер, кнопки меню)
- **Пробел** — открыть/закрыть дверь (недоступно, пока открыты камеры)
- **V** — открыть/закрыть вентиляцию (недоступно, пока открыты камеры)
- **C** — открыть/закрыть камеры
- **1 / 2** — переключение между камерой коридора и камерой зала
- **Esc** — выйти из камер
